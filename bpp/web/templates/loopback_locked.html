Best Photo Picker opens only from the link that was created when it started, so other programs on this computer can't read your library.

  1. Go to the Terminal window running bpp serve and click the link that starts with http://127.0.0.1:5001/?_boot=.
  2. If that window is gone, stop the server (Ctrl+C) and run bpp serve again; it opens the app for you.

Using the Mac app? Quit it and open it again.
