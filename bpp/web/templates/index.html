Computing...

Semantic dedup loads every photo's CLIP fingerprint into memory at once. Peak footprint is ~3x the fingerprint size: the dictionary, the search matrix, and the dedup scratch matrix all live at the same time. The default 200,000-photo cap keeps that under ~1.2 GB — comfortable on a 16 GB machine sharing memory with a browser and the OS. Enabling above the cap is safe as long as you have headroom for the reported peak; if you start seeing the app slow under memory pressure, disable below.
