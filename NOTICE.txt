bpp itself is licensed under the MIT License (see LICENSE). This file

Trust model summary
-------------------
- **Bundled** (ships inside the wheel / repo): permissive only
  (Apache-2.0, BSD-2-Clause, MIT). No copyleft code is checked into
  the repository or shipped in the package.
- **Required runtime**: the Python packages `pip install bppicker`
  pulls in declare permissive licenses (Apache-2.0, MIT, BSD,
  MIT-CMU), plus tqdm (MPL-2.0 AND MIT). Some of their binary wheels
  bundle native libraries under other licenses — notably FFmpeg
  (LGPL-2.1) inside the OpenCV wheel, which on macOS also includes
  libx265 (GPL-2.0). See the OpenCV entry below.
- **Optional runtime**: includes LGPL and GPL components. For
  pip installs, each is an opt-in extra that the user installs
  separately, accepting the terms of the relevant license at install
  time.
- **Desktop app (.app / DMG)**: built with the optional extras
  installed, so it DOES contain those LGPL / GPL components.
  See "Desktop app (.app / DMG)" below.
- **Downloaded at first-use**: ML model weights fetched on demand,
  some from the original publisher and some from third-party
  re-hosts (listed per model below), never from Arkalogy. Some
  weights carry restrictive terms: Ultralytics YOLOv11n is AGPL-3.0,
  NudeNet is AGPL-3.0, and bpp's registry classifies the LaMa and
  insightface buffalo_s weights as research / non-commercial. No
  Ultralytics Python code runs in the user's process.

Build toolchain
---------------

The app's bpp server runs as a sidecar binary built with PyInstaller
in CI. PyInstaller is a build-time tool: it is
never a runtime dependency, never listed in pyproject, and never
distributed itself. What its build embeds in the sidecar binary:

- PyInstaller bootloader + loader —
  GPL-2.0-or-later WITH Bootloader-exception
  Copyright (c) 2010-2023, PyInstaller Development Team
  Copyright (c) 2005-2009, Giovanni Bajo
  https://github.com/pyinstaller/pyinstaller/blob/develop/COPYING.txt
  The Bootloader Exception grants "unlimited permission to link or
  embed compiled bootloader and related files into combinations with
  other programs, and to distribute those combinations without any
  restriction coming from the use of those files." The sidecar binary
  is such a combination; no GPL obligation attaches to bpp through it.
- PyInstaller run-time hooks (PyInstaller/hooks/rthooks) —
  Apache License 2.0 (relicensed upstream specifically for embedding)
- pyinstaller-hooks-contrib run-time hooks
  (_pyinstaller_hooks_contrib/rthooks) — Apache License 2.0.
  Its *standard* hooks are GPL-2.0-or-later but execute at build time
  only (inside CI) and are not copied into the output binary.

Standing constraints that keep the exception valid for us:
  1. Never modify or fork the bootloader — modifications would be
     plain GPL and require source publication of those changes.
  2. Never vendor PyInstaller into this repository or redistribute it
     outside a built combination — that act is plain-GPL distribution.

================================================================
How this notice is kept honest
================================================================

The required-runtime list above is bpp's direct dependencies (no
extras). The recipes below let any auditor (a security reviewer,
future-you) re-check every install path mechanically. Run each recipe
in a fresh venv and compare the grep output against the expected line
below. Anything else is a drift signal — open an issue.

Limits of this check: pip-licenses reports the license each package
DECLARES in its metadata. It cannot see native libraries bundled
inside wheels (FFmpeg / x265 in OpenCV, x265 / libheif in
pillow-heif, LibRaw in rawpy), and it repeats metadata that can
disagree with a project's LICENSE file (face_recognition_models
declares MIT but its LICENSE file is CC0-1.0). Those known cases are
documented above; the expected outputs below reflect what pip-licenses
actually prints for them. For the desktop app, the per-release
inventory described above does list the native libraries each
package installs.

# Base install (must be empty)
    python -m venv /tmp/bpp-license-audit
    /tmp/bpp-license-audit/bin/pip install bppicker
    /tmp/bpp-license-audit/bin/pip install pip-licenses
    /tmp/bpp-license-audit/bin/pip-licenses --from=mixed --order=license \
        --format=plain | grep -iE 'GPL|LGPL|AGPL'
# Expected: empty.

# [faces] (must be empty)
    python -m venv /tmp/bpp-license-audit-faces
    /tmp/bpp-license-audit-faces/bin/pip install "bppicker[faces]"
    /tmp/bpp-license-audit-faces/bin/pip install pip-licenses
    /tmp/bpp-license-audit-faces/bin/pip-licenses --from=mixed --order=license \
        --format=plain | grep -iE 'GPL|LGPL|AGPL'
# Expected: empty. mediapipe (Apache-2.0), scipy (BSD-3-Clause), and
# their transitives are all permissive — anything else is drift.

# [heic] (must be exactly pillow-heif + libheif)
    python -m venv /tmp/bpp-license-audit-heic
    /tmp/bpp-license-audit-heic/bin/pip install "bppicker[heic]"
    /tmp/bpp-license-audit-heic/bin/pip install pip-licenses
    /tmp/bpp-license-audit-heic/bin/pip-licenses --from=mixed --order=license \
        --format=plain | grep -iE 'GPL|LGPL|AGPL'
# Expected: empty with current pillow-heif releases, whose metadata
# declares BSD-3-Clause (older releases carried a GPLv2 classifier and
# show up here). The binary wheel is GPLv2 regardless — see
# LICENSES_bundled.txt inside it.

# [raw] (must be exactly LibRaw)
    python -m venv /tmp/bpp-license-audit-raw
    /tmp/bpp-license-audit-raw/bin/pip install "bppicker[raw]"
    /tmp/bpp-license-audit-raw/bin/pip install pip-licenses
    /tmp/bpp-license-audit-raw/bin/pip-licenses --from=mixed --order=license \
        --format=plain | grep -iE 'GPL|LGPL|AGPL'
# Expected: empty — rawpy declares MIT; the LibRaw (LGPL-2.1) it
# bundles is not a separate Python package, so it doesn't appear.

# [inpaint] (must be empty)
    python -m venv /tmp/bpp-license-audit-inpaint
    /tmp/bpp-license-audit-inpaint/bin/pip install "bppicker[inpaint]"
    /tmp/bpp-license-audit-inpaint/bin/pip install pip-licenses
    /tmp/bpp-license-audit-inpaint/bin/pip-licenses --from=mixed --order=license \
        --format=plain | grep -iE 'GPL|LGPL|AGPL'
# Expected: empty. simple-lama-inpainting (Apache-2.0), torch and
# torchvision (BSD-3) are all permissive — anything else is drift.

Note: pip-licenses run against a dev venv WILL show entries from
tools like `twine`, `readme_renderer`, or `insightface` if they were
manually installed for development. Those are not in the end-user
install path. The clean-venv recipes above are the only reliable
audit.

================================================================
Downloaded at first-use (model weights only)
================================================================

These are fetched over HTTPS the first time a feature is used and
stored in the user's cache directory, after a SHA-256 check. They are
downloaded by the user's installation from the hosts named below —
some are the original publisher, some are third-party re-hosts —
never from Arkalogy. Formats vary (ONNX, TFLite / MediaPipe task
files, a TorchScript .pt for LaMa); no Ultralytics Python code runs
in the host process.

- MediaPipe model weights — Apache License 2.0
  https://github.com/google/mediapipe/blob/master/LICENSE
  Includes BlazeFace full-range face detection, face landmark
  detection, hand detection, pose detection, and selfie segmentation
  models.
  Downloaded from storage.googleapis.com (mediapipe-models /
  mediapipe-assets buckets, Google).
- YuNet face detector ONNX weights — Apache License 2.0
  https://github.com/opencv/opencv_zoo (models/face_detection_yunet)
  Downloaded at runtime from media.githubusercontent.com/media/opencv/opencv_zoo
- SCRFD face detector ONNX weights — research / non-commercial.
  insightface's code is MIT, but its README states that models
  trained on its annotated data, including models downloaded from
  its repository, are for non-commercial research purposes only.
  bpp's registry treats SCRFD as restricted: it is downloaded and
  used only after you accept it, and is blocked when your use context
  is "Commercial" unless you state in the click-through that you hold
  separate rights to it.
  Upstream: https://github.com/deepinsight/insightface
  Runtime download source: a third-party HuggingFace mirror at
  https://huggingface.co/RuteNL/SCRFD-face-detection-ONNX
  (the bnkps variant insightface released, mirrored for stable
  download — SHA-256 pinned in `bpp/scoring/face_scrfd.py` so the
  mirror can't substitute different bytes)
- SFace face embedding ONNX weights — Apache License 2.0
  https://github.com/opencv/opencv_zoo
  Downloaded at runtime from media.githubusercontent.com/media/opencv/opencv_zoo
- CLIP ViT-B/32 ONNX weights (visual + text encoders) — MIT License
  https://github.com/openai/CLIP/blob/main/LICENSE
  Runtime download source: a third-party Hugging Face re-host of an
  ONNX conversion, https://huggingface.co/deepghs/clip_onnx
  (SHA-256 pinned in `bpp/scoring/clip_embed.py`)
- CLIP BPE tokenizer vocabulary — MIT License (OpenAI CLIP)
  Downloaded from openaipublic.azureedge.net (OpenAI)
- YOLOv11n (Ultralytics) ONNX weights — AGPL-3.0
  https://github.com/ultralytics/ultralytics/blob/main/LICENSE
  Downloaded from github.com/ultralytics/assets releases
  Note: Only the exported ONNX weights are downloaded at runtime for
  local inference. The Ultralytics Python package is NOT installed
  and no AGPL Python code runs in the user's process. The ONNX-graph
  format is interpreted by ONNX Runtime (MIT). If the user redistributes
  these weights in their own derived work, AGPL terms attach to that
  redistribution.
- NudeNet 320n ONNX weights — AGPL-3.0 (downloaded only after a
  license click-through; BPP runs them with its own ONNX Runtime code
  and does not install or bundle the NudeNet Python package)
  Downloaded from raw.githubusercontent.com/notAI-tech/NudeNet at a
  pinned commit (see `bpp/scoring/nudity.py`)
- insightface buffalo_s face-analysis bundle — non-commercial research
  use per insightface (opt-in face embedder behind a license
  click-through; blocked for a "Commercial" use context unless you
  state in the click-through that you hold separate rights to it)
  Downloaded from github.com/deepinsight/insightface releases
- LaMa inpainting weights (big-lama.pt) — see the
  simple-lama-inpainting entry above; registry-classified as research
  / non-commercial, behind a license click-through
  Downloaded from the third-party re-host
  github.com/enesmsahin/simple-lama-inpainting (release v0.1.0)
